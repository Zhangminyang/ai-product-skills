# Readiness gates

| Result | Meaning |
| --- | --- |
| `ready` | The primary flow, scope, permissions, states, key rules, and acceptance criteria are clear enough for estimation and test planning. |
| `ready_with_risks` | The core is clear, but remaining low- or medium-risk questions need resolution before or during review. |
| `blocked` | Missing goals, flows, permissions, states, key data rules, or acceptance criteria prevent reliable estimation or test planning. |

High-risk gaps block review, implementation, or test design. Medium-risk gaps should be resolved before development. Low-risk details can be resolved during design or implementation if they do not change scope or acceptance.
