# AI Product Skills

一组面向产品工作的可复用 AI Skills：帮助把信息核验、方案表达和研发准入检查做得更清晰。

## Included skills

| Skill | What it helps with |
| --- | --- |
| [`claim-verify`](skills/claim-verify/) | Trace important claims back to evidence and state their confidence clearly. |
| [`arch-diagram`](skills/arch-diagram/) | Turn a PRD or feature plan into a product architecture diagram by first clarifying structure and boundaries. |
| [`prd-preflight`](skills/prd-preflight/) | Check whether a PRD is ready for engineering review, estimation, and testing. |

## Use

Copy a folder under `skills/` into your Codex skills directory, or use the `SKILL.md` directly as instructions for an AI assistant. Each skill includes its own references and templates where needed.

## Scope

These are general-purpose methods and templates. They intentionally contain no company systems, project data, credentials, or internal workflow requirements.
